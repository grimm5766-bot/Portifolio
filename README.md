# Portfólio | João Pedro Santos Silva

Portfólio pessoal desenvolvido para apresentar projetos, habilidades e formas de
contato de maneira clara, responsiva e acessível.

## Destaques

- Design responsivo para desktop, tablet e celular
- Projetos com demonstrações visuais feitas em HTML e CSS
- Navegação mobile e animações com preferência de movimento reduzido
- Metadados para SEO e dados estruturados
- Sem dependências ou etapa de build

## Executar localmente

Abra o arquivo `index.html` no navegador ou inicie um servidor estático:

```bash
npx http-server . -p 8080
```

Depois, acesse `http://localhost:8080`.
